# TASK-003 — Enter/Esc во всех полях редактора коллекций

## Постановка (со слов пользователя)
Enter работает не везде. В частности, НЕ работает при вводе:
- группы тегов,
- группы лейблов,
- общих событий.

Требование: во **всех** полях ввода редактора коллекций **Enter применяет** написанное,
**Esc выходит** (отменяет/закрывает поле).

## Затронутые файлы (уточнить при старте)
- Кандидаты: `CreateCustomCollectionsView`, `KeyBindingsCollectionEditorView`,
  редакторы групп тегов/лейблов/общих событий в `Modules/VideoPlayer/Views/`.
- Уже есть механика Enter в редакторе (см. память keybindings / `editorEnterKeyPressed`
  нотификация, `FocusStateManager`) — проверить, почему часть полей её не использует.
