# TASK-005 — Кнопка папки автосейва в окне таймлайнов

## Постановка (со слов пользователя)
Дать возможность поменять папку автосохранения во время разметки или установить её, если
не выбрана. Кнопку для этого разместить **в окне таймлайнов**, рядом с остальными кнопками.
Рядом с кнопкой — индикатор: какая папка выбрана (или что не выбрана).

## Контекст (уже есть)
- `ClipAutoSaveManager` (TASK-001): `isFolderConfigured`, `folderName`, `pickFolder()`,
  `resetFolder()` — всё готово, нужен только UI-вход в окне таймлайнов.
- Существующая кнопка `clipAutoSaveButton` в `FullControlView.swift:~1649` — образец.

## План (набросок)
- [ ] Найти окно/вью таймлайнов и ряд кнопок в нём.
- [ ] Добавить кнопку «папка автосейва» + подпись `folderName ?? "не выбрана"`
  (реактивно от `@ObservedObject ClipAutoSaveManager.shared`).
- [ ] Клик → `pickFolder()`. Возможность сменить в любой момент.
- [ ] Сборка проходит.

## Результат
Выполнено 2026-08-03. Кнопка в окне таймлайнов показывает имя папки с центр-сокращением (пап…ка). Механика из TASK-001. BUILD зелёный. См. [[../../HISTORY]].
