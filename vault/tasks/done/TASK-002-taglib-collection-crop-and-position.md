# TASK-002 — Библиотека тегов: crop пустого места + позиция коллекции

## Постановка (со слов пользователя)
Для коллекции связок клавиш (free-layout / canvas связок):
1. В **канвасе** (редакторе) пустое место вокруг объектов оставляем как есть.
2. В **библиотеке тегов** при показе этой коллекции пустого места за пределами объектов
   быть не должно — область строго по bounding box: от самого левого до самого правого,
   от самого верхнего до самого нижнего объекта. Лишнее пустое место убрать.
3. Открывая такую коллекцию в библиотеке тегов, **всегда открывать её в левом верхнем углу**.
   Дальше пользователь сам подвинет/приблизит при необходимости.

## Затронутые модули / файлы (предположительно — уточнить при старте)

  `TagLibraryFreeLayoutFitStore` (хранит fit/лейаут), free-layout вью библиотеки тегов.
- См. память: keybindings canvas multiselect / inline map — там про free-layout редактор.
