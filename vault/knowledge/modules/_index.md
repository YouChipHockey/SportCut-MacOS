# Модули проекта

macOS SwiftUI, MVVM + Combine. Карта кода целиком — [[../architecture]].
Термины: **SportCut = просмотр, VideoPlayer = разметка.**

| Модуль | .swift | Роль | Заметка |
|--------|-------:|------|---------|
| [[VideoPlayer]] | 129 | **Разметка** — главный редактор, мультиоконность | самый крупный |
| [[Telestration]] | 31 | Рисование поверх видео (стрелки, зоны, полигоны) | |
| [[SportCut]] | 21 | **Просмотр** — нарезка клипов, плейлисты, анализ | |
| [[Videos]] | 21 | Библиотека видео, импорт/экспорт/слияние проектов | |
| [[ImagesEditor]] | 5 | Редактор скриншотов/изображений (+ новый таб «Редактор») | два каталога: ImagesEditor и ImageEditor |
| [[Collections]] | 3 | Коллекции тегов: экспорт/бэкап | |
| [[License]] | 2 | Лицензия, Firebase-auth | |

Прочее: `Common/` (файлы, менеджеры, extensions, общие View), `Shared/`, `Resourses/`
(локализации, опечатка намеренная).
