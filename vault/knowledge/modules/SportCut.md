# SportCut (режим «Просмотр»)

Нарезка клипов, плейлисты, анализ. Точка входа UI — `SportCutListView`.

## Ключевые факты (из наработанного опыта)

- **Экспорт**: клипы режутся последовательно (serial), прогресс опрашивается через
  `AVAssetExportSession.progress`, упаковка — streaming zip. Ошибки обязательно
  показывать пользователю, не глотать.
- **Плейлисты / таймлайн**: последовательные таймлайны плейлиста с переопределением
  start/duration на каждое событие, направленный resize, фильтрация рисунков.
- **Разметка в просмотре**: в режиме просмотра показываются рисунки клипов плейлиста
  + скриншоты исходной разметки (два источника данных).
- **Водяной знак клуба**: `ClubLogoWatermarkManager` + редактор настроек; флаг
  `showClubLogo` в `ExportWatermarkOptions`; композитинг в SportCut
  `watermarkVideoComposition`.
