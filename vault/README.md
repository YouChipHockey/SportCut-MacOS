# YouChip-Stat — Vault (база знаний проекта)

Это Obsidian-хранилище — **база знаний проекта**. Смысл: одна сессия Claude работает
inline (без ролевых агентов — они медленные и дорогие по токенам), но перед задачей
**читает нужные заметки здесь**, чтобы не облазить весь код заново. Чем полнее база —
тем быстрее и дешевле задачи.

> Открыть как Vault в Obsidian: `File → Open folder as vault → vault/`.
> `[[ссылки]]` работают и в Obsidian (граф/бэклинки), и как подсказки связей.

## Структура

| Путь | Что внутри |
|------|------------|
| `knowledge/architecture.md` | **Карта кода**: точка входа, паттерны, индекс синглтонов/менеджеров, персистентность, связи модулей. Читать первым. |
| `knowledge/modules/` | По заметке на модуль: ключевые файлы, свои менеджеры, грабли. |
| `knowledge/conventions/` | Стиль кода, локализация. |
| `decisions/` | ADR — почему приняли неочевидное решение. |
| `tasks/` | Лёгкая история задач (`backlog/` → `in-progress/` → `done/`). |
| `HISTORY.md` | **Сквозной журнал** выполненных задач (новые сверху). |

## Рабочий цикл (inline)
1. Прочитать заметку нужного модуля + `knowledge/architecture.md`.
2. Реализовать, собрать проект (команда — ниже).
3. Записать долгоживущий неочевидный вывод обратно в `knowledge/`.
4. **После выполнения задачи — дописать запись в `HISTORY.md`** (правило из `CLAUDE.md`):
   дата, задача, что сделано, как правилось.

## Команда сборки
```bash
xcodebuild -workspace Youchip-Stat.xcworkspace -scheme Youchip-Stat \
  -configuration Debug build CODE_SIGNING_ALLOWED=NO -quiet
```
Успех = exit code 0 (`-quiet` не печатает `BUILD SUCCEEDED`). Ошибки — по `error:`.
SourceKit в редакторе часто врёт (изолированный индексатор) — доверяй `xcodebuild`.

## Ограничение по тестам
Автотестов нет, запуск — из Xcode/симулятора. Проверка = сборка + ручной чек-лист сценариев.

## Правила ведения базы
- Один факт — одно место. Дубль — объединить. Устарело — исправить/удалить.
- Не дублируй то, что и так есть в коде/git. Пиши **почему**, а не **что**.
- Связывай заметки через `[[ссылки]]`.
